# The UI (K5 and L8)

An AutoCAD-like interface (A8), designed first and built after. The design is a claude.ai Design artifact
(https://claude.ai/artifact/J3yNSVKeLNqd6aJnnVQMZ3, one canvas: an overview, the main window in ten states, every
dialog, and four components). The maintainer edits it by hand; it is the source of truth for looks, read before any UI
code. What it cannot show (mouse, keys, dragging) is written down here.

One window holds both parts (A16), laid out as AutoCAD 2021's own (A20): the design follows a screenshot of it. Part A's
controls make up the window; Part B adds model drawings to the file list, a ribbon tab, and model links in Properties.

## The main window

```
┌ Title bar: quick access (new, open, save, undo, redo) · app name and file · search ───────┐
├ Ribbon: Home · [Drawing] · Annotate · View · Plugins · Settings ──────────────────────────┤
│  Draw │ Modify │ Annotation │ Layers (layer box) │ Properties (ByLayer boxes) │ Clipboard │ View
├───────────────┬────────────────────────────────────────────────┬──────────────────────────┤
│ DRAWINGS      │ [-][Model][2D Wireframe]                       │ PROPERTIES               │
│ search        │                                                │ No selection ▾           │
│ filters       │   Canvas (black by default): model space,      │ [owner banner]           │
│ the files:    │   or a layout with viewports;                  │ General                  │
│  DXF files,   │   select, grips, zoom, pan                     │ Plot style               │
│  [model       │                                                │ View                     │
│  drawings]    ├────────────────────────────────────────────────┤ Misc                     │
│               │ Command line: history, prompt, "Type a command"│                          │
├───────────────┴────────────────────────────────────────────────┴──────────────────────────┤
│ Model │ Layout1 │ Layout2 │ +   ·····   [state] · X Y · MODEL  GRID SNAP ORTHO POLAR OSNAP 1:1 │
```

Items in square brackets exist only for a model drawing (Part B). Differences from AutoCAD, all on purpose: no tabs of the
open drawings above the canvas (A20), no ViewCube or navigation bar (A13), and the file list on the left.

| Region | Content | Notes |
|---|---|---|
| Title bar | quick access icons, "GeometryHelper Drawing" and the current file (`*` when changed), a command search box | no tabs of open drawings; switching is by the file list |
| Ribbon | Home (Draw, Modify, Annotation, Layers, Properties, Clipboard, View), Annotate, View, Plugins, Settings; **Drawing** (Drawing, Views, Annotate, Export) only for a model drawing | the Layers panel holds the current-layer box, Make Current and Match Layer; the Properties panel holds the three ByLayer boxes; the Plugins tab lists command plugins, and drawing plugins too when a model drawing is open |
| Left panel · Drawings | search, filters (All, DXF, Model drawings, Out of date), then the drawing files: DXF files grouped by folder, model drawings grouped by source; a dot per file: blue edited, amber out of date (model drawings), green up to date | this is the only content of the panel: no layouts, no layers, no views list (A20); a click opens the file |
| Canvas | model space (black by default) with the label `[-][Model][2D Wireframe]` at its top left, or a layout: the paper with its viewports | see interaction below |
| Model / Layout tabs | bottom left, as AutoCAD: Model, each layout, `+` | a model drawing has the Model tab (its lines at 1:1) and its sheet |
| Right panel · Properties | the selection box ("Line (1)", "Viewport (1)", "Dimension (1)"; several entities show their common properties, mixed values as *Varies*); collapsible groups; each row a label and a value, edited in place | grey values are read-only; an edit is one undo step |
| Owner banner | on top of Properties when the selection is owned by a model drawing: "Owned by drawing B-101. You can move it, edit its text and points. Its value follows the model." | what may be edited comes from the owner contract (D24) |
| Command line | under the canvas only (not under Properties): the history lines, then the input line with the running command's prompt and the placeholder "Type a command" | type a command name or alias (A12) |
| Bottom bar | the Model / Layout tabs at the left; at the right a state text (a DXF: Saved or Unsaved changes; a model drawing: the source's state and the drawings out of date), the cursor coordinates, MODEL or PAPER, and the GRID, SNAP, ORTHO, POLAR, OSNAP toggles, and the annotation scale | clicking the out-of-date count filters the file list |

Panels can be resized and hidden (Ctrl+1 toggles Properties and Ctrl+9 the command line, as in AutoCAD).

Conventions that help the code follow the design:

- Colours, spacing and radii are the tokens named in the design: bg #1E2228, panel #262B33, header #2E343D, input
  #1A1E24, canvas #000000, sheet #FFFFFF, selected #1F4E79, border #3A414C, text #E6E9ED and #9AA4B1, accent #3D9BFF;
  status colours #3FB950, #D29922, #F85149. Inter for text, JetBrains Mono for the command line and values.
- Panel widths: left 288, right 312; the main window frame at 1600 × 960, plus one at 1920 × 1080.
- A colour used twice is a token (`GhBgCanvas`, ...), in WPF resources; Dark and Light are two sets.
- Icons come from an open-source set, never Autodesk's.

## Interaction on the canvas (as AutoCAD)

The canvas is 2D only (A13): a flat drawing, zoomed and panned. There is no 3D orbit, no rotation, no ViewCube.

| Action | Result |
|---|---|
| Mouse wheel | zoom about the cursor |
| Middle button drag | pan |
| Middle button double-click | zoom to everything (ZOOM Extents) |
| Left click | select an entity; Shift+click removes it from the selection |
| Drag left to right | window selection (solid blue box): entities wholly inside |
| Drag right to left | crossing selection (dashed green box): entities touching the box |
| Drag a grip | move a point of the entity; on a viewport or a view, corner grips change its frame and the middle grip moves it |
| Double-click in a viewport | work in its model space (MSPACE); double-click outside returns to paper |
| Esc | cancel the running command, clear the selection |
| Enter or Space | end the command; with no command running, repeat the last one |
| Right click | context menu: repeat, Properties, the commands that suit the selection |
| Hover | highlight the entity a click would select |
| An entity with an owner | a click selects it as any; a command that the owner refuses says so (Messages: "This line belongs to the model") |

Object snaps (OSNAP): endpoint, midpoint, centre, quadrant, intersection, perpendicular, tangent, nearest; F3 toggles
them, the kinds are chosen in Global settings.

## Default commands and shortcuts (A12)

Command names and aliases follow AutoCAD; the app's own commands are named in the same style. All of them can be changed
in Global settings › Shortcuts (as AutoCAD's acad.pgp does, but in the app's own settings file; Autodesk's file is never
copied).

## Technique (proposed)

- WPF; the controls built for net48 and net8.0-windows (D12); the standalone app on .NET 8.
- The canvas drawn with SkiaSharp (MIT) from the display lists of K2; picking through the spatial index, not WPF's hit
  testing.
- Each control has a view model testable without a window; the controls call only the cores' public APIs.
- The theme comes from the design tokens: two sets of resources, Dark and Light, switched at run time from Global
  settings.
