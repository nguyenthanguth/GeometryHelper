# Faults of Tekla's drawings

The faults this module has to get right. They set the order of work in G3 to G5 (Q1). Each gets a test body built in
code that shows it, never the maintainer's model.

| # | Fault (what Tekla does) | What is right | Test | Status |
|---|---|---|---|---|
| T1 | (to be filled in by the maintainer) | | | |

Possible kinds, to help fill the list:

- dimensions overlapping each other or the part, or doubled;
- marks covering marks, dimensions or lines;
- hidden lines wrong: shown where they should not be, or missing;
- views placed badly, overlapping, or off the sheet;
- values wrong or rounded wrongly;
- a drawing that changes when it should not after the model changes, or does not when it should;
- slowness on large assemblies.
