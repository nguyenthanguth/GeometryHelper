# AutoCAD and GeometryHelper

For a reader who knows AutoCAD's .NET API, what each daily pattern is here. The classes not named keep AutoCAD's name with
Dxf in front and their members' names.

| AutoCAD | GeometryHelper | The difference |
|---|---|---|
| `new Database(false, true); db.DxfIn(path, log)` | `DxfDatabase.Open(path)`, `Open(stream)`, `Parse(text)` | A DXF file only, ASCII, R12 to R2018; no DWG and no binary DXF. |
| `new Database(true, true)` | `new DxfDatabase("AC1024")` | The version is named, AC1015 (R2000) to AC1032 (R2018); the drawing is in millimetres. |
| `db.DxfOut(path, 16, version)`, `db.SaveAs(path, version)` | `db.Save(path)`, `Save(stream)`, `ToText()` | Saved in the version, code page and style it was read in; a drawing is not turned into another version. An entity appended from a drawing of another version is turned into this one's forms. |
| `HostApplicationServices.WorkingDatabase`, `Document.LockDocument()` | none | No application and no document: the drawing is the object `Open` gave. |
| `using (Transaction tr = db.TransactionManager.StartTransaction()) { ...; tr.Commit(); }` | none | Every change is written at once; nothing is rolled back. |
| `(Line)tr.GetObject(id, OpenMode.ForWrite)` | the object itself | An object is reached through what holds it (`db.ModelSpace`, a table, `entity.Owner`) and is the same object each time; no `UpgradeOpen`. |
| `ObjectId`, `id.Handle`, `db.GetObjectId(false, handle, 0)` | the object; `obj.Handle`, a text such as `"2F"`; `db.GetObject(handle)`, `db.TryGetObject(handle, out value)` | Entities (VERTEX and ATTRIB among them), objects of the OBJECTS section, and the layer, linetype, text style, dimension style and block tables and their records are found; APPID, VPORT, VIEW and UCS records and a block's BLOCK and ENDBLK, which have no class, are not. A handle of no object throws `KeyNotFoundException` from `GetObject`, as AutoCAD answers eUnknownHandle. A handle of an erased object throws it too, at once, where AutoCAD's `GetObjectId` still gives the erased object's id and fails only when it is opened (eWasErased); `TryGetObject` gives false for both. |
| `ObjectIdCollection`, `DBObjectCollection` | `IReadOnlyList<DxfEntity>` and the like | `Explode()`, `GetOffsetCurves`, `GetSplitCurves`, `GetBlockReferences` give lists of objects. |
| `var bt = (BlockTable)tr.GetObject(db.BlockTableId, OpenMode.ForRead)` | `db.BlockTable` | Also `db.LayerTable`, `LinetypeTable`, `TextStyleTable`, `DimStyleTable`. |
| `bt[BlockTableRecord.ModelSpace]` opened for write | `db.ModelSpace`, `db.PaperSpace`, `db.BlockTable["BOLT"]` | Named `*Model_Space` and `*Paper_Space` whatever the file calls them. |
| `btr.AppendEntity(line); tr.AddNewlyCreatedDBObject(line, true)` | `db.ModelSpace.AppendEntity(line)` | One call; the entity is given a handle and an owner, and its layer is added to the layer table where it is not listed. |
| `foreach (ObjectId id in btr)` | `foreach (DxfEntity e in btr)` | The entities as objects, walked over those the block holds when the walk begins. |
| `entity.Erase()` | `entity.Erase()` | Takes every record of it out; no `Erase(false)` to bring it back. |
| `new Line(p1, p2)`, `new Circle(c, n, r)`, `new Arc(...)`, `new Ellipse(...)`, `new DBPoint(p)` | `new DxfLine(p1, p2)`, `new DxfCircle(c, n, r)`, `new DxfArc(...)`, `new DxfEllipse(...)`, `new DxfDBPoint(p)` | Points are [`GeoPoint3`](xref:GeometryHelper.Geometry.GeoPoint3), directions [`GeoVector3`](xref:GeometryHelper.Geometry.GeoVector3). |
| `Polyline`, `Polyline2d`, `Polyline3d`, `PolyFaceMesh`, `PolygonMesh`, `Spline`, `Ray`, `Xline`, `Face`, `Solid` | [`DxfPolyline`](xref:GeometryHelper.Dxf.DxfPolyline), [`DxfPolyline2d`](xref:GeometryHelper.Dxf.DxfPolyline2d), [`DxfPolyline3d`](xref:GeometryHelper.Dxf.DxfPolyline3d), [`DxfPolyFaceMesh`](xref:GeometryHelper.Dxf.DxfPolyFaceMesh), [`DxfPolygonMesh`](xref:GeometryHelper.Dxf.DxfPolygonMesh), [`DxfSpline`](xref:GeometryHelper.Dxf.DxfSpline), [`DxfRay`](xref:GeometryHelper.Dxf.DxfRay), [`DxfXline`](xref:GeometryHelper.Dxf.DxfXline), [`DxfFace`](xref:GeometryHelper.Dxf.DxfFace), [`DxfSolid`](xref:GeometryHelper.Dxf.DxfSolid) | Their vertices are [`DxfVertex2d`](xref:GeometryHelper.Dxf.DxfVertex2d), [`DxfPolylineVertex3d`](xref:GeometryHelper.Dxf.DxfPolylineVertex3d), [`DxfPolyFaceMeshVertex`](xref:GeometryHelper.Dxf.DxfPolyFaceMeshVertex), [`DxfFaceRecord`](xref:GeometryHelper.Dxf.DxfFaceRecord) and [`DxfPolygonMeshVertex`](xref:GeometryHelper.Dxf.DxfPolygonMeshVertex). |
| `DBText`, `MText` | [`DxfDBText`](xref:GeometryHelper.Dxf.DxfDBText), [`DxfMText`](xref:GeometryHelper.Dxf.DxfMText) | No fonts: a text's `GeometricExtents` is its insertion point, and `AdjustAlignment` is not there. `TextStyleId` is `TextStyle`, the record, beside `TextStyleName`. |
| `BlockReference`, `MInsertBlock`, `AttributeReference`, `AttributeDefinition` | [`DxfBlockReference`](xref:GeometryHelper.Dxf.DxfBlockReference), [`DxfMInsertBlock`](xref:GeometryHelper.Dxf.DxfMInsertBlock), [`DxfAttributeReference`](xref:GeometryHelper.Dxf.DxfAttributeReference), [`DxfAttributeDefinition`](xref:GeometryHelper.Dxf.DxfAttributeDefinition) | `new DxfBlockReference(position, block)` takes the block record, not its id; `AttributeCollection.AppendAttribute` takes the attribute itself. |
| `RasterImage`, `Wipeout`, `RasterImageDef`, `RasterVariables` | [`DxfRasterImage`](xref:GeometryHelper.Dxf.DxfRasterImage), [`DxfWipeout`](xref:GeometryHelper.Dxf.DxfWipeout), [`DxfRasterImageDef`](xref:GeometryHelper.Dxf.DxfRasterImageDef), [`DxfRasterVariables`](xref:GeometryHelper.Dxf.DxfRasterVariables) | Read, moved, clipped and copied; no pixel is read. `Orientation` is `GetOrientation` and `SetOrientation`, an origin and two sides of their lengths, where [`GeoCoordinateSystem3`](xref:GeometryHelper.Geometry.GeoCoordinateSystem3) would make them unit and square. `ImageDefId` is `ImageDef`, the object. See [Images and wipeouts](images.md#images-and-wipeouts). |
| `Ole2Frame`, `Rectangle3d`, `Ole2Frame.ItemType` | [`DxfOle2Frame`](xref:GeometryHelper.Dxf.DxfOle2Frame), [`DxfRectangle3d`](xref:GeometryHelper.Dxf.DxfRectangle3d), [`DxfOle2FrameItemType`](xref:GeometryHelper.Dxf.DxfOle2FrameItemType) | Read, copied, moved and sized as AutoCAD 2021 does, upright; a static picture made of a .bmp or a .png by `new DxfOle2Frame(bytes)`, which AutoCAD's .NET API cannot. The frame is read from and written to the corners in its binary, as AutoCAD reads it; `GetCompoundDocument()` and `GetPictureData(out format)` are the library's own. `OleObject` and `Position2d`, of the running application and its window, are not there. See [OLE objects](images.md#ole-objects). |
| `Hatch`, `Leader`, `MLeader` | [`DxfHatch`](xref:GeometryHelper.Dxf.DxfHatch), [`DxfLeader`](xref:GeometryHelper.Dxf.DxfLeader), [`DxfMLeader`](xref:GeometryHelper.Dxf.DxfMLeader) | A loop is a [`DxfHatchLoop`](xref:GeometryHelper.Dxf.DxfHatchLoop) of the library's shapes; a line of `GetHatchLinesData` is a [`GeoLine2`](xref:GeometryHelper.Geometry.GeoLine2); `EvaluateLeader` is not there. |
| `RotatedDimension`, `AlignedDimension`, `RadialDimension`, `DiametricDimension`, `LineAngularDimension2`, `Point3AngularDimension`, `ArcDimension`, `OrdinateDimension`, `RadialDimensionLarge` | the same with Dxf in front | `RecomputeDimensionBlock` is not there: the block that draws a dimension is left for AutoCAD to draw anew. |
| `Table` | [`DxfTable`](xref:GeometryHelper.Dxf.DxfTable) | Cells read and set; its block is left for AutoCAD to draw anew (`RecomputeTableBlock` is not there); a shear or a scale unlike along its axes refused. `table.Cells[r, c]` is a [`DxfCell`](xref:GeometryHelper.Dxf.DxfCell), `Rows` and `Columns` lists of [`DxfRow`](xref:GeometryHelper.Dxf.DxfRow) and [`DxfColumn`](xref:GeometryHelper.Dxf.DxfColumn); `SetTextStyle` takes the record, not its id. The forms by row type (`SetAlignment(align, rowTypes)` and the like) are not there. |
| `Viewport`, `Layout`, `PlotSettings` | [`DxfViewport`](xref:GeometryHelper.Dxf.DxfViewport), [`DxfLayout`](xref:GeometryHelper.Dxf.DxfLayout), [`DxfPlotSettings`](xref:GeometryHelper.Dxf.DxfPlotSettings) | `db.Layouts` walks the layouts in the order of their tabs; plot settings are read only. `new DxfLayout { LayoutName = "Plan" }` is added by `AddToLayoutDictionary(db, null)`, its block made, and `Initialize()` gives it its viewport 1. `SetSun` takes the [`DxfSun`](xref:GeometryHelper.Dxf.DxfSun) itself and gives it back. |
| `LayerTableRecord`, `LinetypeTableRecord`, `TextStyleTableRecord`, `DimStyleTableRecord` | [`DxfLayerTableRecord`](xref:GeometryHelper.Dxf.DxfLayerTableRecord), [`DxfLinetypeTableRecord`](xref:GeometryHelper.Dxf.DxfLinetypeTableRecord), [`DxfTextStyleTableRecord`](xref:GeometryHelper.Dxf.DxfTextStyleTableRecord), [`DxfDimStyleTableRecord`](xref:GeometryHelper.Dxf.DxfDimStyleTableRecord) | Found by name, either case: `db.LayerTable["steel"]` is the layer Steel, and added by `Add`. A layer, a dimension style and a block are renamed by `Name` with every reference to them; a layer, a linetype, a dimension style and a block are erased by `Erase()` where nothing uses them. |
| `lt.Has("steel")`, `lt["steel"]` giving an `ObjectId` | `db.LayerTable.Has("steel")`, `db.LayerTable["steel"]` giving the record | Null where the table has none. |
| `layer.LinetypeObjectId = ltId` | `layer.LinetypeName = "DASHED"` | Records point at records by name where AutoCAD's point by id, and at the record itself where AutoCAD's property is the record (`Dimtxsty`, `Dimblk`). |
| `DBDictionary`, `Xrecord`, `Group`, `db.NamedObjectsDictionaryId`, `db.GroupDictionaryId` | [`DxfDBDictionary`](xref:GeometryHelper.Dxf.DxfDBDictionary), [`DxfXrecord`](xref:GeometryHelper.Dxf.DxfXrecord), [`DxfGroup`](xref:GeometryHelper.Dxf.DxfGroup), `db.NamedObjectsDictionary`, `db.GroupDictionary` | The dictionaries are objects; `SetAt` takes the object made in code. |
| `ResultBuffer`, `TypedValue` | `IReadOnlyList<DxfTypedValue>`, [`DxfTypedValue`](xref:GeometryHelper.Dxf.DxfTypedValue) | A value is the text the file prints: `new DxfTypedValue(1040, "2.5")`. Setting `XData` registers its application. |
| `Entity.TransformBy(Matrix3d)`, `GetTransformedCopy` | `TransformBy(GeoTransform3)`, `GetTransformedCopy` | Each class refuses what it cannot hold, as AutoCAD's does (see [Editing rules](rules.md#editing-rules)). |
| `Entity.Explode(DBObjectCollection)` | `Explode()` giving a list | The library explodes an INSERT, the three polylines, a polyface and a polygon mesh, an MTEXT, a dimension, a table, a leader, a multileader, an MLINE, a HATCH of a pattern and a MESH not smoothed, as AutoCAD's do; every other entity refuses with `NotSupportedException`, a MINSERT of one cell or more, which AutoCAD refuses too, a HATCH filled solid or with a gradient, a MESH smoothed, a REGION, a 3DSOLID and a BODY among them, which AutoCAD explodes (see [What the model does not do](rules.md#what-the-model-does-not-do)). |
| `BlockReference.ExplodeToOwnerSpace()` | `ExplodeToOwnerSpace()` | The same: the parts appended, the INSERT kept; a MINSERT gives its first cell alone, as AutoCAD 2021's did. |
| `entity.IntersectWith(other, Intersect.ExtendThis, points, IntPtr.Zero, IntPtr.Zero)` | `entity.IntersectWith(other, DxfIntersect.ExtendThis)` giving `IReadOnlyList<GeoPoint3>` | Worked out on the library's shapes; a pair it cannot cross, a text among them, throws `NotSupportedException`, where AutoCAD crosses the box of a TEXT's or an MTEXT's words, which needs the fonts. |
| `GeometricExtents` giving `Extents3d` | `GeometricExtents` giving [`GeoAabb3`](xref:GeometryHelper.Geometry.GeoAabb3) | Of the shapes `GetGeometry()` gives; a text has no fonts to give it a box. |
| `Curve.GetPointAtParameter`, `GetDistAtPoint`, `GetOffsetCurves`, `GetSplitCurves`, `Extend` | the same on [`DxfCurve`](xref:GeometryHelper.Dxf.DxfCurve) | Offsets go the side AutoCAD's do, a line to the left of its way and the rest to the right, as below. |
| `Curve.GetGeCurve()` giving a `Curve3d` | `GetGeCurve()` giving the library's shape ([`GeoLine3`](xref:GeometryHelper.Geometry.GeoLine3), [`GeoArc3`](xref:GeometryHelper.Geometry.GeoArc3), ...) as an `object`; typed, with no cast, `line.ToGeoLine3()`, `polyline.ToGeoPolygonArc2()` and the rest, named as CadConvert names its own | `GetGeometry()` gives the same as [`DxfReader`](xref:GeometryHelper.Dxf.DxfReader) reads it, a LEADER its curve, a [`GeoPolyline3`](xref:GeometryHelper.Geometry.GeoPolyline3) or, splined, a [`GeoSpline3`](xref:GeometryHelper.Geometry.GeoSpline3), and a MULTILEADER the lines of its leaders. A typed conversion of the plane refuses an entity off the floor, where CadConvert's drops z (see [Typed shapes](entities.md#typed-shapes)). |
| `Curve.SetFromGeCurve(curve3d)` | `SetFromGeCurve(shape)` | Takes the shape of space and of the plane, and a polyline a chain or a loop, each written as [`DxfWriter`](xref:GeometryHelper.Dxf.DxfWriter) writes it. |
| `Clone()`, `db.WblockCloneObjects(ids, ownerId, map, DuplicateRecordCloning.Ignore, false)` | `entity.Clone()` then `other.ModelSpace.AppendEntity(copy)`; `db.WblockCloneObjects(entities, other.ModelSpace)` giving the copies | Records of the tables and the blocks a copy draws by come with it where the other drawing has none of their names, its own used where it has (see [Editing rules](rules.md#editing-rules)). No `IdMapping`: the copies are given back in the order of the entities. |
| `Point3d`, `Vector3d`, `Point2d`, `Vector2d` | [`GeoPoint3`](xref:GeometryHelper.Geometry.GeoPoint3), [`GeoVector3`](xref:GeometryHelper.Geometry.GeoVector3), [`GeoPoint2`](xref:GeometryHelper.Geometry.GeoPoint2), [`GeoVector2`](xref:GeometryHelper.Geometry.GeoVector2) | CadConvert turns one into the other: `point.ToGeoPoint3()`, `point.ToAcadPoint3()`. |
| `Matrix3d.Displacement(v)`, `Rotation(angle, axis, centre)`, `Scaling(factor, centre)`, `Mirroring(plane)` | `GeoTransform3.Translation(v)`, `RotationAxis(centre, axis, angle)`, `Scaling(centre, factor)`, `Mirror(plane)` | `a * b` applies `b` first, as `Matrix3d`'s product does. `Matrix3d.AlignCoordinateSystem` from one system to another is `FromCoordinateSystem(to) * ToCoordinateSystem(from)`. |
| `Extents3d`, `Plane`, `CoordinateSystem3d`, [`Tolerance`](xref:GeometryHelper.Tolerance) | [`GeoAabb3`](xref:GeometryHelper.Geometry.GeoAabb3), [`GeoPlane3`](xref:GeometryHelper.Geometry.GeoPlane3), [`GeoCoordinateSystem3`](xref:GeometryHelper.Geometry.GeoCoordinateSystem3), [`Tolerance`](xref:GeometryHelper.Tolerance) | |
| `Color`, `LineWeight`, `Transparency` | [`DxfColor`](xref:GeometryHelper.Dxf.DxfColor), [`DxfLineWeight`](xref:GeometryHelper.Dxf.DxfLineWeight), [`DxfTransparency`](xref:GeometryHelper.Dxf.DxfTransparency) | `DxfColor.FromColorIndex(DxfColorMethod.ByAci, 1)` and `FromRgb(255, 128, 0)`, as AutoCAD's. |
| `db.Clayer = layerId`, `db.Insunits`, `Application.SetSystemVariable("LTSCALE", 2.0)` | `db.Clayer = "steel"`, `db.Insunits`, `db.Ltscale = 2` | Variables of the header and of the OBJECTS section as properties; any other by `GetHeader("$NAME")` and `SetHeader`. |
| `db.Dimasz`, `db.Dimblk = blockId`, `db.GetDimstyleData()`, `leader.SetDimstyleData(style)` | `db.Dimasz`, `db.Dimblk = block`, `db.GetDimstyleData()`, `leader.SetDimstyleData(style)` | The `$DIM` variables of the header read as AutoCAD's metric drawing has them where the header gives none; a block, linetype or text style is the record itself. `dim.FormatMeasurement(value, "")` writes the measurement as AutoCAD does, stacked fractions in the codes of an MTEXT; tolerances, limits and the arc symbol are not part of it. |
| `MLeaderStyle`, `mleader.getOverridedMLeaderStyle(style)` | [`DxfMLeaderStyle`](xref:GeometryHelper.Dxf.DxfMLeaderStyle), `mleader.GetOverridedMLeaderStyle(new DxfMLeaderStyle())` | A multileader style is read, not written: the styles of `db.MLeaderStyleDictionary` as the file holds them, and one made in code given what a multileader is drawn with; `PostMLeaderStyleToDb` is not there. |
| `db.Insert(Matrix3d, other, true)`, `db.Insert("PLATE", other, true)` | `db.Insert(GeoTransform3, other, true)`, `db.Insert("PLATE", other, true)` giving the block | The other drawing's model space, its tables and named blocks merged by name; the other drawing is never changed. |
| `db.Purge(ids)` leaving in `ids` what may be erased; `db.CountHardReferences(ids, counts)` | `db.Purge(objects)` giving those back as a list; `db.CountHardReferences(objects, counts)` | The references a DXF writes by name (a layer, a linetype, a style, a block) counted with the hard pointers. |
| `db.GeoDataObject` giving an `ObjectId`, `GeoLocationData`, `geo.PostToDb()` | `db.GeoDataObject` giving the [`DxfGeoData`](xref:GeometryHelper.Dxf.DxfGeoData), `geo.PostToDb()` | `BlockTableRecordId` is `BlockTableRecord`, the record; `PostToDb` gives nothing back, the GEODATA itself now in the file. `EraseFromDb` is `Erase()`. `NorthDirection` is read only, worked out from `NorthDirectionVector`; `TransformToLonLatAlt`, `TransformFromLonLatAlt` and `UpdateTransformationMatrix` are not there. The members of [`DxfTypeOfCoordinates`](xref:GeometryHelper.Dxf.DxfTypeOfCoordinates) and [`DxfScaleEstimationMethod`](xref:GeometryHelper.Dxf.DxfScaleEstimationMethod) drop AutoCAD's prefixes: `CoordinateTypeLocal` is `Local`, `ScaleEstMethodUnity` is `Unity`. A [`DxfMeshPointMap`](xref:GeometryHelper.Dxf.DxfMeshPointMap) is read only, where AutoCAD's `MeshPointMap` sets its two points. |
| `db.LayerStateManager.GetLayerStateNames(false, false)`, `LayerStatesDictionaryId(false)` | `db.LayerStateManager.GetLayerStateNames(false, false)`, `LayerStatesDictionary` | A state is hidden where its mask has the flag 0x8000 and of an xref where its record names its layers by name; `GetLayerStateNames()` gives every state. `LayerStatesDictionary` is read only and makes no dictionary. Saving, restoring, renaming, deleting, importing and exporting a state are not there. |
| `db.LayerFilters` giving a `LayerFilterTree` | `db.LayerFilters` giving a [`DxfLayerFilterTree`](xref:GeometryHelper.Dxf.DxfLayerFilterTree) | Read only: no `Current`, and a tree is not set back. A [`DxfLayerFilter`](xref:GeometryHelper.Dxf.DxfLayerFilter)'s `Name` has no setter; `FilterExpression` and `Filter(layer)` are not there. |
| `Highlight`, `Draw`, grips, overrules, events, reactors of the runtime | none | They need AutoCAD running. |

The classes of AutoCAD's own geometry (`Point3d`, `Line`, `Polyline`, `Arc`, `Ellipse`, `Spline` and the rest) are turned into the library's shapes and back by the bridge, [GeometryHelper.CadConvert](../../../GeometryHelper.CadConvert/README.md).
